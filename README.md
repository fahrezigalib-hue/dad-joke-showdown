# Dad Joke Showdown

Entry for the make.fun bounty **u-mfnakmal-dad-joke-showdown-1d2ce3e5**
("Dad Joke Showdown").

`main.ts` is a self-contained Node program: it writes the entry line to
`/output/entry.txt`, deterministically — the same bytes on every run,
no network, no clock, no randomness.

The line:

> I named my dog Six Miles, so every morning I can honestly tell people I walk Six Miles before breakfast.
